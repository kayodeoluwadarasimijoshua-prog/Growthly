# Claims omitted or replaced from the Stitch export

The owner authorized using the uploaded Stitch design as a visual reference, not treating its generated business claims as facts. Its four HTML pages and screenshots were reviewed before implementation. The exported HTML/scripts were not copied into the production application.

| Reference content | Treatment in the implemented design |
| --- | --- |
| “+180% Corporate Inquiries” | Omitted. No measured enquiry uplift was supplied. |
| “High-Converting” / ROI promises | Replaced with clear presentation, service scope and enquiry goals, without promising an outcome. |
| 0.64s FCP, under 1.2s mobile loading, sub-2s performance guarantee, 98/100 score labels | Omitted as customer promises. Any locally measured performance is reported separately with its test conditions. |
| 99.98% uptime guarantee, 99.9% availability target, Tier-3 cloud SLA | Omitted; no approved service-level agreement was supplied. |
| 100% on-time handover / SLA compliance / WhatsApp routing | Omitted. Scope, milestones, contact routes and review are explained without invented statistics. |
| Guaranteed 7–14 day delivery, under-one-hour responses, proposals within 24 hours, universal 30-day support | Replaced with timing, support and responsibilities agreed in the written proposal. |
| CAC RC 1984210, “Growthly Studio Limited”, formal tax/invoice claims | Omitted. The design uses the confirmed Growthly identity without asserting a legal registration or tax status. |
| NiRA accreditation / registrar-partner badges | Omitted. The first-year domain offer remains subject to availability and the written scope. |
| Victoria Island / Ikeja GRA offices and Lagos studio/hub claims | Omitted. The business serves Nigerian customers without inventing an office. |
| +234 (0) 800 GROWTHLY, hello@growthly.com.ng | Omitted. Existing published CMS contacts remain authoritative; confirmed code defaults are retained. Private account emails are not marketing contacts. |
| NDPR/GDPR compliance or encryption claims | Omitted as certifications/guarantees. The actual privacy notice explains the implemented handling and optional AI processing. |
| ₦35,000–₦55,000 annual renewals and a fixed advance-invoice period | Omitted. Renewal prices and responsibility are confirmed in writing rather than invented. |
| Fixed creative-service fees and expanded package deliverables | Not adopted from the export. Existing approved package/CMS prices and separately agreed creative scope remain in use. |
| StarXCO catalogue management, vessel manifests and encrypted executive lead routing | Not adopted as case-study facts. Existing approved descriptions and scope remain authoritative. |
| AutoVault represented as a real luxury/commercial dealership or a client | Replaced with its accurate self-initiated demonstration status, real interface screenshot, sample inventory description and AI-artwork disclosure. |
| Placeholder links and simulated pricing controls | Replaced with real existing routes, service-specific briefs, native disclosures and current CMS-backed website packages. No pretend purchase flow was added. |
| Inflated team biographies or unsupported seniority/credentials | Replaced with the owner-supplied names and actual responsibilities. Initials remain until genuine permitted photos are published. |
| Paid-ad campaign examples/results | None added. The owner confirmed no completed ad-campaign work is available to feature yet. |

The visual direction keeps the deep green/mint palette, warm neutral surfaces, rounded panels, readable typography, project previews and strong closing action. Copy instead explains what Growthly does, shows approved work, distinguishes client work from demos and gives the customer a relevant next step.
